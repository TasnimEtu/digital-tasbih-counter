# ☪ Digital Tasbih Counter

A simple, lightweight, cross-platform **Digital Tasbih** desktop and web application built with HTML, CSS, and JavaScript.

## Features
- **Bismillah Welcome Screen:** Displays "بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ" upon launching the application.
- **Royal Navy & Gold Theme:** Designed with a calm deep navy blue and gold Eid-inspired aesthetic.
- **Custom Dhikr Folders:** Select default dhikr or add/delete custom dhikr with Arabic text.
- **Target & Progress Tracking:** Set custom targets with a live progress bar, completed rounds, and lifetime total counter.
- **Tactile Sound Feedback:** Plays a crisp click sound on every tap.
- **Tasbih Counter Controls:**
  - **TAP TO COUNT:** Increments the dhikr count by 1.
  - **-1:** Decrements the count safely (prevents negative values).
  - **Reset:** Resets the current count and rounds back to 0.
- **Cross-Platform Desktop Support:** Bundled for Windows (`.exe`), Linux (`.deb` / `.AppImage`), and macOS (`.dmg`).

## Technologies Used
- HTML5, CSS3, JavaScript
- Electron & Electron Builder (for cross-platform desktop packaging)
