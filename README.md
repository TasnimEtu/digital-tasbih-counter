# Digital Tasbih Counter

A lightweight, clean, and user-friendly Digital Tasbih desktop and web application built with HTML, CSS, and JavaScript.

## Features
- **Arabic Salam Greeting:** Displays "السَّلَامُ عَلَيْكُمْ" upon launching the application.
- **Islamic Aesthetic Theme:** Designed with calming green shades and scattered white crescent moon and star graphics.
- **Tasbih Counter Controls:** 
  - **COUNT:** Increments the dhikr count by 1.
  - **-1:** Decrements the count safely (prevents negative values).
  - **Reset:** Resets the counter back to 0.
- **Cross-Platform Desktop Support:** Bundled for Windows (`.exe`), Linux (`.deb` / `.AppImage`), and macOS (`.dmg`).

## Technologies Used
- HTML5, CSS3, JavaScript
- Electron & Electron Builder (for cross-platform desktop packaging)
